# Mapa de riscos de Goiana

[Abrir o mapa](https://wesleyttiago.github.io/goiana-mapa-riscos/)

Minha parte do projeto: RF03, mapa interativo e marcadores por vulnerabilidade.
Feito com React, Leaflet e agrupamento de pontos. Os 2.000 pontos da demo são fictícios.

```bash
npm install
npm run dev
```

`npm test` roda os testes. `npm run build` gera a versão final.

Para integrar no projeto do grupo: [docs/integracao.md](docs/integracao.md).
